Adaptateur entrant (adapters/driving), à compléter. Il dessine les choix du premier lancement, les onglets Lire et Modifier, le formulaire, la boîte de confirmation accessible, la table des matières, les messages d'erreur, la mise en page proche de Vector et la version téléphone. Il appelle les cas d'usage et traduit les codes d'erreur du domaine ; sans framework (ADR 0003). Son point de départ existe : la coquille de l'interface, qui porte déjà l'en-tête et le sélecteur de langue.
